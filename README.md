2. Description
FitLog helps you plan and track your daily workouts and a full fitness-tracking app.It can mark workout as done as you complete them, save others for later, no sign-up, no backend database, just a fast, focused workout companion.
<br>
3.Technologies Used <br>
Next.js<br>
React <br>
TypeScript <br> 
Tailwind CSS <br>
react-toastify <br>
react-icons <br>
<br>
4.Key Features<br>
1.Full workout library all twelve lifts from the FitLog API rendered as a responsive grid, each with a category tag, equipment line, and a duration or calories or rating stats row.<br>
2.Live navbar badges  with Plan and Saved pill counters in the navbar update instantly as workouts are added or removed, both linking to my-plan.<br>
3.Workout detail pages a two column layout with a full bleed image.<br> 
4.A numbered instructions list, plus Add to today's plan and Save for later actions with toast confirmations.<br>
5.My Plan dashboard  live Exercises and minutes and calories summary cards. <br>
