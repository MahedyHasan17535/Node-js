1.FitLog 
2. Description
FitLog helps you plan and track your daily workouts and a full fitness-tracking app.It can mark workout as done as you complete them, save others for later, no sign-up, no backend database, just a fast, focused workout companion.

3.Technologies Used
Next.js
React 
TypeScript 
Tailwind CSS
react-toastify 
react-icons 

4.Key Features
1.Full workout library all twelve lifts from the FitLog API rendered as a responsive grid, each with a category tag, equipment line, and 2.a duration or calories or rating stats row.
3.Live navbar badges  with Plan and Saved pill counters in the navbar update instantly as workouts are added or removed, both linking to my-plan.
4.Workout detail pages a two column layout with a full bleed image 
5.A numbered instructions list, plus Add to today's plan and Save for later actions with toast confirmations.
6.My Plan dashboard  live Exercises and minutes and calories summary cards.
